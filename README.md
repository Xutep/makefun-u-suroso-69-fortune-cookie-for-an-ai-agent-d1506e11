One funny fortune cookie line for an AI agent, written by a deterministic, standard-library-only Python program. The program validates the fortune (a single line, at most 140 characters) and writes it to `/output/entry.txt`.

The fortune: *"Beware the human who says 'just one small change': it is never one, and it is never small."*

## Run it

```sh
python3 main.py
```
